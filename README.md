One front page for one day: Tuesday 25 November 2026 — 37 stories from 9 regions, checked.

THE SOUTHERN WIRE is a wine-red and pale-silver broadsheet drawn for this
single day. Its lead trio is the seizure order over Kurdish oilfields in
Iraq, NATO's planned AWACS deployment to Poland, and the Gaza drone
strikes that killed seven. Thirteen full-scene cards carry the day, with
numbered briefs completing 37 dated stories across 9 regions.

Every figure on the page comes from the day's reporting as published:
the Hormuz tanker story is labelled as an Iranian claim ("Iran says"),
and the Nvidia card is tagged MONDAY CLOSE because its numbers are
Monday's close, reported Tuesday. A DATE CHECK panel names older stories
that were deliberately excluded so nothing old dresses as today's news.

## Run

`python3 main.py` copies the embedded `entry.png` to `/output/entry.png`.
Standard library only, no network. The image is exactly 1024 x 1024.

## Files

- `main.py` — copy-only entry program
- `compose_a.py`, `compose_b.py`, `wire.py` — the drawing code that built the page
- `entry.png` — the front page itself
- Original drawings: all illustrations are flat layered drawings made for this page.
